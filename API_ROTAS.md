# Rotas de API (Vercel + MongoDB)

Base: `https://anotacoes-hidroponia.vercel.app`

| Método | Rota | Uso |
|--------|------|-----|
| POST | `/api/transaction` | Registrar |
| GET | `/api/transactions` | Listar |
| GET | `/api/summary` | Resumo |
| PUT | `/api/transaction/{id}` | Editar |
| POST | `/api/transaction/{id}/riscar` | Riscar |
| DELETE | `/api/transaction/{id}` | Excluir |
