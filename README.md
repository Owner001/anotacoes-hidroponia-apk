# Anotações Hidroponia — APK Android

App que abre a interface em **https://anotacoes-hidroponia.vercel.app/app**  
(API + MongoDB ficam no servidor).

## Baixar o APK

1. https://github.com/Owner001/anotacoes-hidroponia-apk/actions
2. Workflow **Build APK** → **Run workflow**
3. Espere ficar verde (~3–5 min)
4. Artifacts → **app-debug-apk** → baixe e instale `app-debug.apk`
